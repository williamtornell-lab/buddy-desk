# Buddy

Trading desk for William. Open the URL Buddy sends you (it includes `#d=…`).

Home shows the paper stack, night P&L versus the start stack, an equity chart, open positions, and per-coin trade P&L. Activity is the blotter and the tape. Agents is heartbeats, with settings tucked behind a disclosure.

`STATE.md` lists the `state.json` fields. `snapshot_state_patch.py` is the helper Buddy runs on the box to fill `equity` and `trades`.
